## ۱. ماتریس آیزنهاور چیه؟

ماتریس آیزنهاور یک ابزار مدیریت زمانه که Dwight Eisenhower (رئیس‌جمهور آمریکا) ابداعش کرد. ایده ساده‌ای داره: هر کار رو بر اساس دو بعد می‌سنجیم — **مهم بودن (Importance)** و **فوری بودن (Urgency)**. ترکیب این دو بعد، چهار ربع می‌سازه:

| | **فوری** | **غیرفوری** |
|---|---|---|
| **مهم** | 🔴 **Q1** — بحران: همین الان انجام بده | 🟡 **Q2** — رشد: برنامه‌ریزی کن |
| **غیرمهم** | 🟠 **Q3** — حواس‌پرتی: واگذار کن/کمتر کن | ⚪ **Q4** — اتلاف وقت: حذف کن |

**چرا این تقسیم‌بندی جواب می‌ده؟** چون مغز ما معمولاً کارهای *فوری* رو به کارهای *مهم* ترجیح می‌ده. ایمیل میاد جلوی یادگیری مهارت جدید. ماتریس آیزنهاور مجبورت می‌کنه قبل از شروع کردن، *ارزش واقعی* کار رو بسنشی. مشکل اصلی بقیه To-do List ها اینه که همه کارها رو مساوی فرض می‌کنن؛ Pixi این مشکل رو با ربع‌بندی + امتیاز حل می‌کنه.

### Pixi چه فرقی با بقیه‌ها داره؟

- **امتیاز منفی واقعی داره:** اگه بری سراغ کارهای بی‌ارزش در حالی که کار مهم دارید، امتیازت *کم میشه*. تنبیه واقعی = انگیزه واقعی.
- **توی ترمیناله:** بدون رفرش مرورگر، بدون اپ اضافه. هرجا SSH داری، Pixi هم داری.
- **دیتا مال خودته:** همه‌چیز توی چند فایل JSON ساده کنار پروژه — نه سرور، نه اکانت، نه کلود.

## ۲. نصب و راه‌اندازی

### پیش‌نیاز

فقط **Python 3.9 به بالا** لازمه. چک کن:

```bash
python3 --version
```

### نصب (روش پیشنهادی)

```bash
git clone https://github.com/BitEngineX/pixi.git
cd pixi
pip install -e .
```

بعد از این، دستور `pixi` در همه‌جا در دسترسه:

```bash
pixi gui      # رابط گرافیکی ترمینالی
pixi stats    # آمار سریع
```

### نصب بدون نصب‌کردن (سریع‌ترین راه)

```bash
git clone https://github.com/BitEngineX/pixi.git
cd pixi
pip install -r requirements.txt
python main.py
```

### محل ذخیره دیتا

به‌صورت پیش‌فرض فایل‌های دیتا کنار کد ساخته میشن:

- `tasks.json` — درخت تسک‌هات (پوشه‌ها، تسک‌ها، ربع‌ها، اولویت‌ها)
- `daily_state.json` — امتیاز زنده امروز
- `daily_scores.log` — آرشیو امتیاز هر روز
- `logs.json` — آخرین ۵۰۰ فعالیت

اگه می‌خوای دیتا یه جای دیگه باشه (مثلاً پوشه‌ای که sync میشه):

```bash
export PIXI_DATA_DIR="$HOME/pixi-data"
pixi gui
```

## ۳. اولین اجرا — تور رابط گرافیکی (TUI)

```bash
pixi gui
```

با این صحنه روبه‌رو میشی:

```
┌──────────────────────────────────────────────────────────┐
│  Pixi — Eisenhower Matrix   —  Manage tasks. Score...    │
│  ┌─ Dashboard ─┬─ Reports ─┬─ Logs ─┐                    │
│  │ درخت تسک‌ها  │           │        │                    │
│  │  + جستجو    │  ماتریس    │  لیست   │                    │
│  │  + امتیاز   │  Q1..Q4   │  Todo  │                    │
│  └─────────────┴───────────┴────────┘                    │
│  n New Task │ f New Folder │ c Complete │ s Change Quad  │
└──────────────────────────────────────────────────────────┘
```

سه پنل اصلی:

1. **پنل چپ — درخت تسک‌ها:** پوشه‌ها (`[F]`) و تسک‌ها (`[T]`). با جستجوی بالای پنل، بین همه‌ی تسک‌ها سرچ کن.
2. **پنل وسط — ماتریس:** چهار ربع Q1 تا Q4. هر ربع اولویت‌بندی داخلی داره (بالا = مهم‌تر).
3. **پنل راست — Todo List:** همه کارهای در صف، مرتب‌شده بر اساس ربع و اولویت. این «میز کار» اصلی توئه.

### کلیدهای میانبر (مهم‌ترین‌ها)

| کلید | کار | توضیح |
|------|-----|-------|
| `n` | تسک جدید | زیر پوشه/آیتم انتخاب‌شده |
| `f` | پوشه جدید | برای دسته‌بندی (Work, Personal, ...) |
| `r` | تغییر نام | |
| `d` | حذف | با تایید `y` |
| `s` | تعیین ربع | مهم‌ترین کلید! تسک رو به Q1–Q4 می‌بره |
| `c` | تکمیل | دیالوگ امتیاز باز میشه |
| `←` / `→` | جابه‌جایی اولویت | داخل یه ربع، بالا/پایین کن |
| `e` / `w` | باز/بسته کردن همه | |
| `q` | خروج با ذخیره | |

> **قانون طلایی:** تسک جدید اول میره Inbox (بدون ربع). با `s` انتخابش کن و بگو واقعاً کجای ماتریس می‌شه. این همون لحظه‌ی «فکر کردن قبل از انجام» هست که کل ماتریس بهش اتفاق میفته.

## ۴. کار با CLI

CLI برای سرعت و اتوماسیونه. بدون باز کردن TUI کارتو راه بنداز:

### افزودن و مرتب‌سازی

```bash
# افزودن تسک به پوشه (بخشی از اسم پوشه کافیه)
pixi add "تماس با مشتری" --folder Work

# فقط تسک‌های بدون ربع (Inbox)
pixi list --inbox

# بردن تسک به ربع — از UID خروجی list استفاده کن
pixi move <UID> Q1
```

### تکمیل با امتیاز

```bash
# value اندازه/ارزش کاره (پیش‌فرض 1)
pixi complete <UID> --value 2
```

خروجی:

```
✅ Task completed!
   Added score: 300.00
   Daily score: 300.00
```

### گزارش‌گیری

```bash
pixi stats                    # آمار ماتریس الان
pixi report                   # امتیاز هر روز
pixi report --date 2026-10-04 # روز مشخص
pixi log --limit 10           # آخرین فعالیت‌ها
```

### نکته UID

هر تسک یه UID طولانی داره. موقع تایپ، **چند حرف اول یکتاش** کافیه — یا از کپی‌کردن استفاده کن. اگه ترجیح میدی، کارهای روزمره رو با TUI انجام بده و CLI رو برای گزارش و اسکریپت نگه دار.

## ۵. سیستم امتیازدهی — منطق بازی

قلب Pixi اینجاست. هر ربع یه امتیاز پایه داره:

| ربع | معنی | فرمول | مثال با value=2 |
|-----|------|-------|------------------|
| 🔴 Q1 | مهم و فوری | `600 ÷ value` | **+300** |
| 🟡 Q2 | مهم و غیرفوری | `value × 350` | **+700** |
| 🟠 Q3 | غیرمهم و فوری | `0` | **0** |
| ⚪ Q4 | غیرمهم و غیرفوری | `value × (−150)` | **−300** |

### چرا Q1 تقسیم میشه و Q2 ضرب؟

طراحی هوشمندانه‌ست:

- **Q1 (بحران‌ها):** کارهای فوری معمولاً کوچیکن و هرچی دیرتر، گرون‌تر. فرمول `600 ÷ value` یعنی کارهای کوچیک (value کم) امتیاز بیشتری میدن — پس *همین الان* انجامشون بده و سود کن. تعلل = ضرر.
- **Q2 (سرمایه‌گذاری):** کارهای مهم غیرفوری (ورزش، یادگیری، برنامه‌ریزی) بزرگن و ارزششون با اندازه‌شون ضرب میشه. هرچی بیشتر بذاری، بیشتر می‌گیری.

### قوانین فشار (Pressure Rules)

1. **اگه Q1 داری و بری سراغ Q2 → امتیاز Q2 نصف میشه.** اول آتیش رو خاموش کن، بعد رشد کن.
2. **اگه هر کار مهمی (Q1/Q2/Q3) معلق باشه و بری سراغ Q4 → جریمه دوبرابر.** نتفریلیکس بعد از کار، نه وسط کار.
3. **Q3 امتیاز نداره** — چون کار *یکی دیگه* رو انجام دادی، نه مال خودتو.
4. **امتیاز روز میتونه منفی بشه** — تلف‌کردن کامل روز، یه عدد سرخ توی گزارش می‌ذاره.

### ریست روزانه

وقتی روز عوض میشه (اولین اجرای روز بعد)، امتیاز دیروز قفل میشه و میره توی `daily_scores.log`، و از صفر شروع می‌کنی. با `pixi report` روند چند روز اخیرت رو ببین — این «خط روند» بهترین معیار پیشرفته.

## ۶. گردش کار پیشنهادی روزانه

روتینی که با سیستم Pixi جور درمیاد:

**صبح (۵ دقیقه):**
1. `pixi gui` رو باز کن
2. کارهای جدید دیروز/امروز رو با `n` اضافه کن
3. همه Inbox ها رو با `s` تریاژ کن — صادق باش: چندتاش واقعاً Q1 هست؟
4. `c` نزن! اول لیست Todo رو مرتب کن

**طول روز:**
5. از Todo List کار بردار، `c` بزن، value رو صادقانه وارد کن
6. وسط روز اگه کار جدید اومد، فقط به Inbox اضافه‌ش کن — جلسه تریاژ بعدی رو بهم نریز

**شب (۲ دقیقه):**
7. `pixi report` رو ببین — امتیاز امروز در برابر روزهای قبل
8. `q` بزن. تمام.

**هر هفته:** به `pixi stats` نگاه کن — نسبت Q2 به Q1 معیار سلامت بلندمدته. اگه Q1 همیشه شلوغه، یعنی برنامه‌ریزی Q2 کم کاری.

## ۷. سوالات پرتکرار (FAQ)

**س: دیتام کجاست؟ پشتیبان‌گیری چطور؟**
فایل `tasks.json` کل دیتاست. همون یه فایل رو کپی کن — یا کل `PIXI_DATA_DIR`. JSON متنیه، با git هم قابل مدیریت.

**س: می‌تونم روی چند سیستم استفاده کنم؟**
آره — دیتا رو توی یه پوشه sync‌شده (Dropbox/Syncthing) بذار و `PIXI_DATA_DIR` رو بهش اشاره بده. یا از یک سیستم SSH بزن به اون یکی.

**س: UID ها طولانی و زشت نیستن؟**
برای CLI درسته، ولی TUI هیچ وقت UID نمی‌خواد. برای اسکریپت‌نویسی UID یکتا یک قابلیته، نه باگ.

**س: امتیازها رو می‌تونم عوض کنم؟**
بالای هر دو فایل `main.py` و `pixi.py` سه ثابت `NQ1_BASE`، `NQ2_BASE`، `NQ4_BASE` هست — تغییرشون بده و ری‌استارت کن. (نسخه‌های آینده این رو توی فایل کانفیگ می‌برن — به [Roadmap](../README.md#-roadmap) سر بزن.)

**س: چرا تکمیل تسک Q1 با value=0 خطا نمیده؟**
میده — صفر مجاز نیست چون فرمول تقسیم میشه. Value منفی هم منطق امتیاز رو به‌هم می‌ریزه؛ از اعداد مثبت استفاده کن.

**س: ویندوز پشتیبانی میشه؟**
بله — پایتون و Textual کراس‌پلتفرمن. Windows Terminal یا PowerShell جدید بهترین تجربه رو داره (cmd قدیمی یونی‌کد ضعیفی داره).

## ۸. رفع اشکال

**«No folder found» موقع add:** CLI پوشه نمی‌سازه — یه بار با `pixi gui` (کلید `f`) پوشه بساز، یا `examples/sample_tasks.json` رو به پوشه دیتات کپی کن.

**رندر به‌هم‌ریخته TUI:** پنجره ترمینال رو بزرگ کن (پیشنهاد: حداقل ۱۲۰×۴۰). فونت‌های Nerd Font ظاهر بهتری میدن ولی اجباری نیستن.

**امتیاز امروز صفر نشد ولی روز عوض شده:** ریست فقط موقع اجرا چک میشه — یه بار `pixi gui` یا هر دستور CLI رو اجرا کن، رول‌اور خودکار انجام میشه.

**خطای نصب `pip install -e .`:** مطمئن شو pip نسخه جدید داره: `pip install --upgrade pip setuptools`. توی سیستم‌های لینوکسی با پیام PEP 668، از venv استفاده کن: `python3 -m venv .venv && source .venv/bin/activate`.
